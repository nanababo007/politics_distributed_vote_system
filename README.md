<br />분산서버 투표 시스템
<br />회의 주제/안건별로 보기 생성, 투표 선택 시스템
<br />투표 정보를 여러 조직의 분산서버에 두어서, 여러 조직에서 관리하여,
<br />데이터 조작을 어렵게 만듬.
<br />분산서버 관리 조직수가 수십개를 넘어가면, 조작을 많이 해봐야 몇개 정도이고,
<br />조작된 정보와 비조작된 정보의 구분은, 다수 일치하는 데이터가 비조작된 정보이고, 
<br />소수 조직의 조작된 데이터가 조작된 정보로 인식.
<br />그 외에, 데이터 부분 단위로 조직 구성원의 개인 피씨에 저장된 자료를 참조하여 확인하거나,
<br />구성원의 일부 기억들을 모아서, 일부 비 조작 데이터를 감별하여, 비조작 서버를 판별하는 등의 보조 판별법도 있음.
<br />
<br />---
<br />
<br />정당 전체 위원회로만 구성
<br />공천위원회 당대표위원회 모두다 위원회 분업 연합 연계
<br />전체업무 필수 과정 메모 기록 내부 전체 공개원칙
<br />소수 비공개 업무 존재 없음
<br />인사과 내부 위원회 인사 수행 인사정보관리
<br />주요위원회 위원장직 회의주제 및 기타 미분류 업무 담당
<br />나머지 모든 업무는 위원회 회의로 보기 선택 투표로만수행 원칙
<br />위원장직 등 주요 인사는 인사과에서 정보자료 작성
<br />인사선택권은 당대표위원회나 전체 위원회 위원장 회의에서 결정 방식 등
<br />모든 업무 인사에 대해 정당내청원사이트에서 전내부당원이 이의재기 가능
<br />처리방법 당대표위원회에서 회의해서 보기도출 전체 내부당원투표 의사결정
<br />잘못된 부분 바로잡는 방법
<br />투표서버 분산관리 랜덤 접속 서버 다수 관리 타조직 관리위원회 배속
<br />다수 투표 데이터 동일데이터 분산저장
<br />조회시 랜덤 다수 분산데이터 호출 투표조작 방지
<br />
<br />---
<br />
<br />암호화 없이, 회의 안건별로 보기를 생성해서, 투표를 하고, 
<br />선택 번호별 투표건수, 기권수, 미참여건, 참여구성원 정보/미참여구성원정보 등의 데이터를, 
<br />데이터가 생성될때, 여러 서버에 동기화 되어 api 를 통해서, 데이터베이스가 동기화 되면서, 
<br />여러서버에 저장되는 방식의, php 나 자바 솔루션으로 구현
<br />매일 등 정기적으로 모든 분산서버를 관리하는 각 조직들은, 데이터베이스 백업 파일을 생성하여,
<br />암호적용 압축을 하여, 블록체인 클라우드에 파일을 저장하는 식으로 백업 관리.
<br />아니면 여러 클라우드 서비스에 분산하여 저장하여, 이중으로 데이터 조작을 방지함.
<br />정기적으로 데이터 조작 여부 확인 업무도 수행함.
<br />
<br />---
<br />
<br />내부에서 여러 위원회에 동일한 투표 시스템을 구축하고, 
<br />투표 시 랜덤으로 분산된 특정 위원회의 분산서버로 접속하여 투표가 수행되고,
<br />해당 투표 수행 시, 내부 분산 위원회별 투표서버들에 api 가 호출되면서,
<br />해당 투표 데이터가 반영이 되면서, 데이터가 동기화 되는 방법, 반영 시 기존 데이터는 백업하여,
<br />조작에 대비한 데이터 변경 전 기존 데이터는 반드시 백업 받음. 이력 누적 처리.
<br />
<br />---
<br />
<br />카프카나 레드마인 등의 메시지 서버를 운영하여, 
<br />정기적으로 정당 내부의 투표 시스템의 데이터베이스 백업 파일폴더를 
<br />추가된 백업파일이 발생했는지 확인 테이블 등을 생성하여, 체크하고, 
<br />신규 추가된 백업파일이 발생하면, 설정된 외부의 서버 아이피로 메시지를 발송하여, 
<br />신규 추가된 데이터베이스 백업 파일을 다운로드 하는 api url 정보를 메시지에 담아서 발송함.
<br />설정된 외부 조직의 외부 수신 서버에서, 메시지에 담긴 api url 의 신규추가 데이터베이스 파일을 다운로드 하여, 
<br />적절하게 각 외부 조직의 전산관리 체계에 맞게 저장하여, 차후에 문제가 발생 시에, 백업된 데이터베이스 파일을, 
<br />절차에 의하여 제공하는 방식의 업무 절차로 운영되는, 조작불가 운영시스템을 구축함.
