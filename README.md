<br />분산서버 투표 시스템
<br />회의 주제/안건별로 보기 생성, 투표 선택 시스템
<br />투표 정보를 여러 조직의 분산서버에 두어서, 여러 조직에서 관리하여,
<br />데이터 조작을 어렵게 만듬.
<br />분산서버 관리 조직수가 수십개를 넘어가면, 조작을 많이 해봐야 몇개 정도이고,
<br />조작된 정보와 비조작된 정보의 구분은, 다수 일치하는 데이터가 비조작된 정보이고, 
<br />소수 조직의 조작된 데이터가 조작된 정보로 인식.
<br />그 외에, 데이터 부분 단위로 조직 구성원의 개인 피씨에 저장된 자료를 참조하여 확인하거나,
<br />구성원의 일부 기억들을 모아서, 일부 비 조작 데이터를 감별하여, 비조작 서버를 판별하는 등의 보조 판별법도 있음.
